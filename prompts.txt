# Technical Implementation Details

## ByteSize and TimeDuration Implementation

1. Grammar modifications in Directives.g4:
   - Added lexer rules for BYTE_SIZE and TIME_DURATION tokens
   - Implemented helper fragments BYTE_UNIT and TIME_UNIT
   - Updated parser rules to handle new token types

2. Token Implementation:
   - Created ByteSize class with unit conversion methods
   - Created TimeDuration class with unit conversion methods
   - Added BYTE_SIZE and TIME_DURATION to TokenType enum
   - Implemented parsing for byte size values (B, KB, MB, GB, TB)
   - Implemented parsing for time duration values (ms, s, m, h)

## AggregateStats Directive Implementation

1. Directive Structure:
   - Created AggregateStats class implementing Directive interface
   - Implemented argument parsing for source and target columns
   - Added support for both single values and arrays

2. Aggregation Logic:
   - Implemented byte size aggregation with unit conversion
   - Implemented time duration aggregation with unit conversion
   - Added error handling for invalid values
   - Implemented store-based aggregation using ExecutorContext

## Testing Implementation
